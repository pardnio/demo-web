## 樣式

| 項目 | 內容 |
|---|---|
| SCSS 入口 | `sass/index.scss` |
| 輸出 CSS | `css/index.css` |
| Partials | `_nav.scss`, `_header.scss`, `_footer.scss`, `_section-0.scss`, `_section-1.scss`, `_section-2.scss`, `_section-3.scss`, `_section-4.scss` |

`index.scss` 含 reset 與 `body>section` 背景（nth-child 4 為品牌深色；nth-child 5、7，即區塊 2 與區塊 4，為背景圖加 ::after 模糊遮罩）；各 partial 以 [num] 區塊對應樣式。顏色與寬度變數（--width-max、--col-brand、--col-brand-light、--col-brand-dark）定義在 `index.html` 的 inline `<style>`，不在 SCSS。編譯後 CSS 的 header background-image 在 `_header.scss` 中找不到。

```bash
cd target/20230605
npx sass sass/index.scss css/index.css --no-source-map || exit 1
```

## 使用技巧

- 以 inline :root 宣告 CSS 變數做主題色。
- 以 .mobile / .tablet 在 640px 顯示切換；版面斷點 480px、800px。
- 背景圖區塊以 ::after 疊加 backdrop-filter 模糊遮罩。
- 以 @media (hover: hover) and (pointer: fine) 做卡片 hover；固定導覽與行動版 .show 覆蓋樣式。
