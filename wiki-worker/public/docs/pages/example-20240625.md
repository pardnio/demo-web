# Zeczec

Multi-page crowdfunding platform mockup modeled on zeczec (嘖嘖), using QuickUI 0.6.2 `:for` loops: home, explore, project, FAQ, comments, proposal and auth pages.

## Interactions

- index.html / search.html: `new QUI({ id: "app", data: {...} })` with `list_4` and `list_6` (index.html) or `list_12` (search.html) renders the `:for` card loops.
- project.html: fetches `@pardnchiu/nanomd@1.8.5` README.md and, in `when.rendered`, constructs an `MDViewer` with the fetched text as `emptyContent` and appends it to `section.markdown`.
- Other pages are static HTML (no inline script besides GA and JSON-LD).

## Styling

| Item | Value |
|---|---|
| SCSS entry | `sass/index.scss` |
| Output CSS | `css/index.css` |
| Partials | `_init.scss`, `function/_hsbTohsl.scss`, `animation/_pie.scss` |

`_init` defines `$_2`..`$_2160` rem spacing variables (including `$_1140`) and the reset; `function/_hsbTohsl` provides `hsb()`/`hsba()` color functions; `animation/_pie` holds pie keyframes imported inside the project data circle. `index.scss` sets the `font-family` of `*` to Arial, Helvetica, sans-serif and styles every page block (nav, home-1..3, project-1..4, start-1..3, login, footer, `.md-viewer`).

```bash
cd target/20240625
npx sass sass/index.scss css/index.css --no-source-map || exit 1
```

## Techniques

- QuickUI `:for="(e, i) in list_n"` template loops over placeholder arrays.
- CSS `attr()` for badges (`content: attr(data-text)`, `attr(data-hint)`); progress bars via `[data-percent="0"]`..`[data-percent="90"]` selectors in steps of 10; SCSS `@for`-generated pie progress using `[percent][done]` and CSS vars (`--pie-*`).
- SCSS spacing variable scale and custom `@function hsb()`; `@media (hover: hover)` hover-only effects; single breakpoint `$_1140` (71.25rem).
- Inline SVG logo and logotype; nav-logo and background-color keyframes.
