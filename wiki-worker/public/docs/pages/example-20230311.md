## Interactions

- `js/index.js`: `body.onscroll` toggles `.scroll` on `#nav-002` past 48px using PDRenderKit string helpers (`"nav-002".$._class` / `class_`)
- `js/index.js`: converts custom attributes `top` / `bottom` / `bg-col` / `col` / `bg-img` into inline padding-top, padding-bottom, background-color, color, background-image (`bg-col` / `col` values starting with `--` become `var(--x)`)
- `js/index.js`: replaces `span[mask]` (`arc` / `arc-up` / `arc-down` / `slash-left` / `slash-right` / `wave`) with generated inline SVG dividers sized from the viewport width (64/128px above 1024px)
- Inline script `showContent(this)`: accordion, clicking a button toggles `.show` on its li and closes the other open li
- `js/index.js` wraps logic in DOMContentLoaded and relies on PDRenderKit prototype extensions (`$all`, `$attr`, `_style`, `$style`, `$parent`, `_class`, `class_`)

## Techniques

- Theme via CSS custom properties in an inline `<style>` `:root` (`--col-nav`, `--col-system`, `--col-txt`, `--col-border`, `--max-width`)
- Attribute-driven layout: `section[num=N]` / `section[header=N]` / `nav[num]` select a pre-built SCSS block; `ul.r2` / `.r3` / `.r4` pick 2/3/4 column cards
- Fixed top nav with collapsed hamburger button; media queries at 413/479/639/799/1023/1039/1139px max-width and 480/640/768/1024/1040px min-width
- JS-generated SVG section dividers (arc / slash / wave) via `span[mask]`
- SEO head: Open Graph, Twitter card, canonical, JSON-LD WebPage schema
- `section/_015` split into `_015-top` / `_015-center` / `_015-bottom` partials for the multi-block article layout
