## Styling

| Item | Value |
|---|---|
| SCSS entry | `sass/index.scss` |
| Output CSS | `css/index.css` |
| Partials | `_nav.scss`, `_header.scss`, `_footer.scss`, `_section-0.scss`, `_section-1.scss`, `_section-2.scss`, `_section-3.scss`, `_section-4.scss` |

`index.scss` holds reset and `body>section` backgrounds (nth-child 4 brand-dark; background image with blurred ::after overlay on nth-child 5 and 7, i.e. Section 2 and Section 4); each partial styles the matching section via [num] blocks. Color/width vars (--width-max, --col-brand, --col-brand-light, --col-brand-dark) are defined in an inline `<style>` in `index.html`, not in SCSS. The compiled CSS sets a header background-image that `_header.scss` does not contain.

```bash
cd target/20230605
npx sass sass/index.scss css/index.css --no-source-map || exit 1
```

## Techniques

- CSS custom properties declared in inline :root style for theming.
- Responsive show/hide helper classes .mobile / .tablet at 640px; layout breakpoints 480px and 800px.
- ::after overlay with backdrop-filter blur over background-image sections.
- @media (hover: hover) and (pointer: fine) for card hover; fixed nav with mobile overlay styles for .show.
