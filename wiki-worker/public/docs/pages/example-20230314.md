## Interactions

- `js/index.js`: `body.onscroll` past 48px calls the PDRenderKit string helpers `"top-nav".$._class` / `class_` to toggle `.scroll` on `#top-nav`
- `js/index.js`: converts custom attributes top / bottom / bg-col / col / bg-img into inline padding-top, padding-bottom, background-color, color, background-image (values starting with -- become var(--x))
- `js/index.js`: replaces `span[mask=arc|arc-up|arc-down|slash-left|slash-right|wave]` with generated inline SVG dividers sized from the viewport width (64/128px above 1024px)
- `js/index.js`: elements with `unhover="1"` get `.unhover` for 500ms on mouseleave
- `js/index.js` wraps logic in DOMContentLoaded and relies on PDRenderKit prototype extensions (`$all`, `$attr`, `_style`, `$style`, `$parent`, `_class`, `class_`)

Shared section library: `index.scss` imports every nav/header/section/footer partial inside body (`nav/_body.scss` is pulled in by the nav partials, the 015-top/center/bottom parts by `section/_015.scss`); each partial is keyed by an attribute selector (nav[num], section[header=N], section[num=N], footer[num]); `comp/*` are mixin-like snippets imported inside sections (r2/r3/r4 responsive column widths, div-info title block, w-h-rate in section 021). `component/_info.scss` and `section/_rm-1st-top.scss` exist but are not imported. This copy's `header/_002.scss` and `section/_015-center.scss` differ from 20230302. `image/full.svg` and `half.svg` exist but are not referenced.

## Techniques

- Theme via CSS custom properties in an inline `<style>` :root (--col-nav, --col-system, --col-txt, --col-border, --max-width)
- Attribute-driven layout: section[num=N] / section[header=N] / nav[num] select a pre-built SCSS block; ul.r2/.r3/.r4 pick 2/3/4 column cards
- Fixed top nav with collapsed hamburger button; media queries at 413/479/639/799/1023/1039/1139px max-width and 480/640/768/1024/1040px min-width
- JS-generated SVG section dividers (arc / slash / wave) via span[mask]
- SEO head: Open Graph, Twitter card, canonical, JSON-LD WebPage schema
- Same section num (21) reused twice with different bg-col to vary appearance
