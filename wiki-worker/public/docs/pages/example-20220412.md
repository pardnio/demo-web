Same module library as 20220409 (reset inlined at top of the entry, no `_init` / function imports); each module is scoped by `div[sn=XXXX]`. Only 6 modules are used by the page.

```bash
cd target/20220412
npx sass sass/PDWebsitemplate.min.scss css/PDWebsitemplate.min.css --no-source-map || exit 1
```

## Techniques

- Attribute-driven module system: `sn` module ids, `df="x2"` / `df="x4"` column grids, `df="btn col fff xxl"` buttons, `wh="1"` image frames, `df="bg"` background blocks.
- Theme set by CSS variables in inline `<style>` on `*`: red `--col-sys` `rgb(200, 30, 60, 0.9)`, `--col-sys-light` / `--col-sys-hint` / `--col-sys-dark`, `--max-width` 1140px, `--default-radius` 0.5rem, `--module-hint` 1 (shows module labels).
- Desktop-first max-width media queries (413 / 479 / 639 / 767 / 959 / 1023px) and pointer-fine hover with keyframe color transitions; CSS-only hover dropdown.
