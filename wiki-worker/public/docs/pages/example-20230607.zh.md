## 互動行為

- inline script 於 DOMContentLoaded 呼叫 PDRenderKit `_LazyListener()`，以 `"a"._(["img"._({src})])` 建立 20 個作品項目放入 DocumentFragment，再以 `portfolio._child()` 插入。

## 樣式

| 項目 | 內容 |
|---|---|
| SCSS 入口 | `sass/index.scss` |
| 輸出 CSS | `css/index.css` |

單檔 SCSS（無 partial）：reset、含 .sel 底線的固定導覽、header 毛玻璃卡、[num="0"]..[num="4"] 各區塊、頁尾，以及讓按鈕與卡片漸層背景移動的 linear-move keyframes。HSL 品牌色階變數（--col-brand-lightest..darkest，色相 271）與 --width-max 1280px 定義於 `index.html` inline `<style>`。

```bash
cd target/20230607
npx sass sass/index.scss css/index.css --no-source-map || exit 1
```

## 使用技巧

- 以 CSS 變數定義 HSL 七階色階（色相 271）。
- 動態漸層：linear-gradient 搭配 @keyframes linear-move 移動 background-position。
- PDRenderKit 元素工廠 `"tag"._(children|attrs)` 與 `element._child()` 建 DOM；`_LazyListener()` 延遲載入圖片。
- 斷點 640/644/800/1024px；backdrop-filter 模糊；位移 box-shadow 裝飾。
