## Interactions

- js/index.js (module): reads ?page via `location.href.$query("page")` (default home), maps it to `nav_index`, and creates new PD({id: "app"}); index.html uses :if / :else-if="page == ..." blocks to choose which :path views load.
- event.tabShow toggles .show on the previous sibling of the menu button; event.section7Click sets index on the carousel container from the dot's data-index.
- On load it fetches https://cdn.jsdelivr.net/npm/pdmarkdownkit@1.6.0/README.md before creating the PD instance; on ?page=article, next() mounts a PDMarkdownKit viewer into section.md after 500ms.

## Techniques

- Client-side routing by query string with PD :if / :else-if conditional blocks and :path partial includes; one HTML file serves 7 pages.
- Attribute interpolation in bindings (:class="fa-solid fa-{{ e }}", :src="./image/app{{ e }}.png"), :for with index, :data-index, :bg-image, nested :if.
- Carousel and layout state through [index] attributes with SCSS @for-generated margin-left offsets per breakpoint.
- Inline SVG injection via span.svg[src]; content: attr(txt) button labels; sticky nav; breakpoints 480px, 512px, 640px, 800px, 960px, 1024px, 1120px.
