## Styling

| Item | Value |
|---|---|
| SCSS entry | `sass/PDWebsitemplate.min.scss` |
| Output CSS | `css/PDWebsitemplate.min.css` |
| Partials | `function/_hsbTohsl.scss`, `_init.scss`, `_PDModuleTop.scss (top/_T-001, _T-002, _T-003, _T004)`, `_PDModuleColum.scss (colum/_C001..._C019)`, `_PDModuleBottom.scss (bottom/_B001-_B003, _BC001-_BC006)`, `_PDModuleAnimation.scss`, `_PDModuleComp.scss (comp/_a[btn], _dev.a[shadow], _div[bg], _img[ic], _to, _wh)` |

The full module library is compiled even though the page uses only 7 modules; each module is scoped by `div[sn=XXXX]` and prints its code via `::after` with opacity controlled by `--module-hint`. `sass/index.scss` (imports `_init`, `_header-0`, `_section-1`) is a separate entry not linked by the page.

```bash
cd target/20220409
npx sass sass/PDWebsitemplate.min.scss css/PDWebsitemplate.min.css --no-source-map || exit 1
```

## Techniques

- Attribute-driven modules: `sn="T002"` etc. select module styles; `df="x2"` / `df="x3"` column layouts, `df="btn fff col xl"` button variants, `wh="1"` image wrappers, `df="sd"` shadow cards.
- Theme via CSS custom properties in an inline `<style>` on `*`: `--col-sys` (green `rgb(30, 120, 50, 0.9)`), `--max-width` 1140px, `--default-radius` 0.25rem, `--module-hint` 1.
- Desktop-first max-width breakpoints (413 / 479 / 639 / 767 / 959 / 1023px) and `(hover: hover) and (pointer: fine)` hover rules with keyframe color transitions.
- CSS-only hover dropdown in the navbar; links collapse (`display: none`) below 640px.
