## 樣式

| 項目 | 內容 |
|---|---|
| SCSS 入口 | `sass/PDWebsitemplate.min.scss` |
| 輸出 CSS | `css/PDWebsitemplate.min.css` |
| Partials | `function/_hsbTohsl.scss`, `_init.scss`, `_PDModuleTop.scss (top/_T-001, _T-002, _T-003, _T004)`, `_PDModuleColum.scss (colum/_C001..._C019)`, `_PDModuleBottom.scss (bottom/_B001-_B003, _BC001-_BC006)`, `_PDModuleAnimation.scss`, `_PDModuleComp.scss (comp/_a[btn], _dev.a[shadow], _div[bg], _img[ic], _to, _wh)` |

即使頁面只用 7 個模組仍編譯整套模組庫；每個模組以 `div[sn=XXXX]` 為範圍，並以 `::after` 顯示模組代號，透明度由 `--module-hint` 控制。`sass/index.scss`（引入 `_init`、`_header-0`、`_section-1`）是頁面未引用的另一個入口。

```bash
cd target/20220409
npx sass sass/PDWebsitemplate.min.scss css/PDWebsitemplate.min.css --no-source-map || exit 1
```

## 使用技巧

- 屬性驅動模組：`sn="T002"` 等選擇模組樣式；`df="x2"` / `df="x3"` 欄數、`df="btn fff col xl"` 按鈕變化、`wh="1"` 圖片外框、`df="sd"` 陰影卡。
- 主題以 inline `<style>` 於 `*` 設定 CSS 變數：`--col-sys`（綠 `rgb(30, 120, 50, 0.9)`）、`--max-width` 1140px、`--default-radius` 0.25rem、`--module-hint` 1。
- 桌面優先 max-width 斷點（413 / 479 / 639 / 767 / 959 / 1023px），並以 `(hover: hover) and (pointer: fine)` 搭配 keyframe 顏色過場處理 hover。
- 導覽列為純 CSS hover 下拉；640px 以下連結隱藏（`display: none`）。
