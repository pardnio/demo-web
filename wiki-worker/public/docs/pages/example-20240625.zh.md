# 嘖嘖募資平台

以嘖嘖為基底的群眾募資平台多頁範例，使用 QuickUI 0.6.2 :for 迴圈：首頁、探索、專案、常見問題、留言、提案與會員頁。

## 互動行為

- index.html／search.html：`new QUI({ id: "app", data: {...} })` 搭配 `list_4` 與 `list_6`（index.html）或 `list_12`（search.html）渲染 `:for` 卡片迴圈。
- project.html：抓取 `@pardnchiu/nanomd@1.8.5` 的 README.md，於 `when.rendered` 以抓回的文字作為 `emptyContent` 建立 `MDViewer` 並附加到 `section.markdown`。
- 其他頁面為靜態 HTML（除 GA 與 JSON-LD 外無 inline script）。

## 樣式

| 項目 | 內容 |
|---|---|
| SCSS 入口 | `sass/index.scss` |
| 輸出 CSS | `css/index.css` |
| Partials | `_init.scss`, `function/_hsbTohsl.scss`, `animation/_pie.scss` |

`_init` 定義 `$_2` 至 `$_2160` 的 rem 間距變數（含 `$_1140`）與 reset；`function/_hsbTohsl` 提供 `hsb()`／`hsba()` 色彩函式；`animation/_pie` 為圓餅 keyframes，於專案數據圓圈內引入。`index.scss` 將 `*` 的 `font-family` 設為 Arial, Helvetica, sans-serif，並涵蓋所有頁面區塊（nav、home-1..3、project-1..4、start-1..3、login、footer、`.md-viewer`）。

```bash
cd target/20240625
npx sass sass/index.scss css/index.css --no-source-map || exit 1
```

## 使用技巧

- QuickUI `:for="(e, i) in list_n"` 模板迴圈搭配佔位陣列。
- 以 CSS `attr()` 顯示標籤（`content: attr(data-text)`、`attr(data-hint)`）；`[data-percent="0"]` 至 `[data-percent="90"]`（每 10 一級）選擇器控制進度條；SCSS `@for` 產生以 `[percent][done]` 與 CSS 變數（`--pie-*`）的圓餅進度。
- SCSS 間距變數尺度與自訂 `@function hsb()`；`@media (hover: hover)` 僅在可 hover 裝置套用；單一斷點 `$_1140`（71.25rem）。
- 內嵌 SVG Logo 與字標；nav-logo 與 background-color keyframes。
