## 互動行為

- `js/index.js`：`body.onscroll` 在 `scrollTop > 48`px 時對第一個 `<nav>` 加上 `.scroll`，低於時移除（原生 DOM）
- `js/index.js`：將自訂屬性 `top` / `bottom` / `bg-col` / `col` / `bg-img` 轉為 inline padding、背景色、文字色、背景圖（`bg-col` / `col` 以 `--` 開頭的值轉為 `var(--x)`）
- `js/index.js`：把 `span[mask]`（`arc` / `arc-up` / `arc-down` / `slash-left` / `slash-right` / `wave`）替換成依 viewport 寬度產生的 inline SVG 分隔曲線（>1024px 時 64/128px）
- `js/index.js`：`unhover="1"` 元素在 mouseleave 時加上 `.unhover` 500ms，播放離開動畫（本頁無 unhover 元素）
- inline script `showContent(this)`：手風琴，點按鈕切換所屬 li 的 `.show` 並關閉其他已展開項目
- `js/index.js` 為原生 DOM（`querySelectorAll` / `getAttribute`）；雖載入 PDRenderKit，但頁面腳本未使用

## 使用技巧

- inline `<style>` `:root` 以 CSS 變數設定主題（`--col-nav`、`--col-system`、`--col-txt`、`--col-border`、`--max-width`）
- 屬性驅動版型：`section[num=N]` / `section[header=N]` / `nav[num]` 對應預製 SCSS 區塊；`ul.r2` / `.r3` / `.r4` 選 2/3/4 欄卡片
- 固定頂部導覽列與漢堡按鈕；media query 斷點 max-width 413/479/639/799/1023/1039/1139px、min-width 480/640/768/1024/1040px
- 以 `span[mask]` 由 JS 產生 SVG 區塊分隔（弧形 / 斜切 / 波浪）
- SEO head：Open Graph、Twitter card、canonical、JSON-LD WebPage schema
- inline 定義含多種前綴的 linear-gradient 工具類 `.linear-bg-1` / `.linear-bg-2`
