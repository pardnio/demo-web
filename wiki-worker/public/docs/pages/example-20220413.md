## Interactions

- Inline script in T004 nav: `#btn-nav-show` adds `show` to the T004 block and sets body overflow to hidden; `#btn-nav-collaspe` adds `collaspe` to the nav, then after 300ms removes it and `show` and sets body overflow to scroll (`T004-nav-show` / `T004-nav-collaspe` keyframes).
- `js/PDWebsitemplate.js` (IntersectionObserver hover / tap `act` + `unhover` helper) is in the folder; `index.html` does not load it.

```bash
cd target/20220413
npx sass sass/PDWebsitemplate.min.scss css/PDWebsitemplate.min.css --no-source-map || exit 1
```

## Techniques

- CSS-only pie chart: two half-circle layers rotated by `calc(3.6deg * N)` per `percent` attribute, value shown with `content: attr(percent)`.
- Responsive column naming `df="w_3_2_1"` = 3 / 2 / 1 columns across breakpoints using `calc(100% / n - 2rem)`.
- Theme CSS variables in inline `<style>` on `*`: `--col-sys` `rgb(185, 120, 200, 0.9)`, `--default-radius` 1rem, `--max-width` 1140px, `--module-hint` 1.
- Full-screen mobile nav with keyframe show / collapse animations and body overflow toggle.
