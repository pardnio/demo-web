## 互動行為

- T004 導覽列 inline script：`#btn-nav-show` 對 T004 區塊加 `show` 並將 body overflow 設為 hidden；`#btn-nav-collaspe` 對導覽列加上 `collaspe`，300ms 後移除它與 `show` 並將 body overflow 設為 scroll（搭配 `T004-nav-show` / `T004-nav-collaspe` keyframes）。
- 資料夾內有 `js/PDWebsitemplate.js`（IntersectionObserver 的 hover／點擊 `act` 與 `unhover` 輔助）；`index.html` 未載入此檔。

## 使用技巧

- 純 CSS 圓餅圖：依 `percent` 屬性以 `calc(3.6deg * N)` 旋轉兩個半圓層，數值以 `content: attr(percent)` 顯示。
- 響應式欄位命名 `df="w_3_2_1"` = 各斷點 3 / 2 / 1 欄，寬度為 `calc(100% / n - 2rem)`。
- inline `<style>` 於 `*` 設定主題變數：`--col-sys` `rgb(185, 120, 200, 0.9)`、`--default-radius` 1rem、`--max-width` 1140px、`--module-hint` 1。
- 全螢幕行動選單，keyframe 展開／收合動畫並切換 body overflow。
