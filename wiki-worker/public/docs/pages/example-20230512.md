## Interactions

- `index.html` inline `<script>` defines global PDConfig (home / about / portfolio data); body is empty and `js/index.js` builds the whole DOM with PDRenderKit element builder (`"tag.class"._([...])`, `_child`, `_click`, `_go`, `_open`)
- Tab routing via `?page=home|about|portfolio` (read with `location.href.$url.$query("page")`, default home): setHome / setAbout / setPortfolio update the query with `$url.__query().__history()`, move .sel and replace section.right-body children (`__child`)
- On load `"button.sel".$.click()` renders the page matching the query
- `js/index.js` setHome → updateTitle: typing/erasing animation on #typing-area every 8s using setInterval/setTimeout
- #show-nav toggles body.show to open/close the sidebar on narrow screens

## Styling

| Item | Value |
|---|---|
| SCSS entry | `sass/index.scss` |
| Output CSS | `css/index.css` |
| Partials | `_left-bar.scss`, `_home.scss`, `_about.scss` |

`index.scss` holds resets, :root vars (--tab-width 0/240/360px at 800/1024px, --head-width 10rem/12rem at 1024px) and the portfolio grid (--album-row-width 1/2/3 columns at 640/1280px); `_left-bar` styles the fixed sidebar, `_home` the background hero with ::before overlay, `_about` the profile, fact tiles, skill bars ([year=N] loop) and timelines.

```bash
cd target/20230512
npx sass sass/index.scss css/index.css --no-source-map || exit 1
```

## Techniques

- Data-driven SPA: content in a config object, DOM built entirely in JS, no markup in `<body>`
- Query-string routing with history update instead of separate HTML files
- CSS variables redefined inside media queries (800px / 1024px) to resize sidebar and avatar
- Skill bars via attribute selectors [year=N] generated by SCSS loop and content: attr(skill) / attr(year) "年"
- Fixed sidebar with responsive breakpoints at 414/480/640/800/1024/1280/1440px
