## Interactions

- js/index.js (module): new PD({id: "app", data, next}) renders the page; each `view/*.html` carries its own inline script creating a PD instance for its section id.
- Scroll reveal: in next(), after 300ms + 300ms, an IntersectionObserver watches every `*.delay` element and removes the delay class (`elm.class_("delay")`) when it enters view; CSS transitions do the reveal.
- view/child9.html: event.send alerts the :model-bound name, email and message.

## Techniques

- PDRenderKit PD templating: :path partial loading on section/header elements, :for, :class / :src / :href binding, {{ }} interpolation, :model two-way input, :html, @click events.
- IntersectionObserver-driven reveal by removing a .delay class with CSS transitions.
- `env(safe-area-inset-*)` CSS variables; position: sticky nav; offset box-shadow; breakpoints 480px, 640px, 800px, 1024px.
